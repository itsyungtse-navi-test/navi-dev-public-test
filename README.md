# navi-dev-public-test
รีโพสิทอรีสาธารณะสำหรับทดสอบสภาพแวดล้อมการพัฒนาของ Navi

## 🐍 เกมงู (Snake)

เกมงูที่ทำงานบนฝั่งหน้าเว็บล้วน ๆ ด้วย HTML + Canvas + JavaScript แบบดั้งเดิม (Vanilla JavaScript) โดยไม่มีการพึ่งพาไลบรารีภายนอกใด ๆ

### วิธีเล่น

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้ทันที (ไม่ต้องใช้เซิร์ฟเวอร์)

| การควบคุม | ปุ่ม |
|---|---|
| เคลื่อนที่ | ปุ่มลูกศร / WASD; บนมือถือสามารถปัดหน้าจอหรือใช้ปุ่มทิศทางบนหน้าจอ |
| เริ่มเกม | Enter |
| หยุดชั่วคราว / เล่นต่อ | Spacebar หรือ P |
| เริ่มใหม่ | R |

กินอาหารหนึ่งชิ้นได้ +10 คะแนน และทุก ๆ 50 คะแนนความเร็วจะเพิ่มขึ้นหนึ่งระดับ คะแนนสูงสุดจะถูกบันทึกไว้ในเบราว์เซอร์ (localStorage)

### โครงสร้างไฟล์

```
index.html            หน้าเว็บและสไตล์
src/logic.js          ตรรกะหลัก (ฟังก์ชันบริสุทธิ์ ไม่แตะ DOM): การเคลื่อนที่ การเลี้ยว การกินอาหาร การชน การนับคะแนน
src/main.js           การวาดบน Canvas, อินพุตจากคีย์บอร์ด/หน้าจอสัมผัส, ลูปของเกม, การบันทึกคะแนนสูงสุด
tests/logic.test.js   ยูนิตเทสต์ของตรรกะหลัก
```

### การทดสอบ

ต้องใช้ Node.js 18 ขึ้นไป โดยใช้ test runner ที่มีมาในตัว ไม่ต้องติดตั้งแพ็กเกจเพิ่ม:

```bash
npm test
# หรือ
node --test tests/logic.test.js
```
